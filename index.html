    Correo de presentación

    Un primer contacto breve y personalizado con una galería, curaduría, residencia o convocatoria. Se arma con los datos de tu dossier; revísalo y ajústalo antes de enviarlo.

    • Escribe a una persona o equipo concreto y menciona algo real de su programa.
    • Una sola propuesta clara; el detalle va en el dossier enlazado.
    • Prefiere un enlace a un adjunto pesado, salvo que las bases pidan un archivo.
    • Si no hay respuesta, un único seguimiento cordial después de unas semanas es suficiente.

          CREAR / PORTADA

          La primera impresión, sin adornar tu trayectoria.

          Usa tu nombre, el título real del proyecto y una imagen representativa.

          CREAR / STATEMENT

          Explica las preguntas que sostienen tu obra.

          No existe una longitud universal. Ajusta el texto a cada convocatoria y evita afirmaciones que no puedas respaldar.

          Una estructura útil
          1. Pregunta o impulso central.
          2. Materiales y decisiones de proceso.
          3. Relación con el contexto o el público.

          Texto curatorial y créditos

          Propio del catálogo artístico. Incluye un texto curatorial solo si existe y tienes autorización para publicarlo.

          CREAR / BIOGRAFÍA

          Trayectoria verificable, escrita con claridad.

          Incluye solo formación, exposiciones o hitos reales. Una práctica emergente no necesita fingir credenciales.

          Servicios y especialidad

          Propio del portafolio comercial: qué haces para clientes, estudios o marcas.

          CREAR / PROPUESTA

          Una idea clara y realizable.

          Completa solo lo que pidan las bases de la convocatoria o el espacio. Cada oportunidad define sus propios requisitos.

          CREAR / OBRAS

          Construye una secuencia, no un inventario.

          Empieza con una obra fuerte y ordena el resto para mostrar relaciones, ritmo y escala.

          □

          Aún no hay obras

          Añade la primera pieza para comenzar la secuencia editorial.

          CREAR / CURRÍCULUM

          Añade únicamente información real.

          Las filas comienzan vacías. Si una categoría no aplica, déjala fuera del documento.

          CREAR / CONTACTO

          Haz que sea fácil continuar la conversación.

          Comparte solo los datos que quieras publicar en el PDF.

          APRENDER / REFERENTES

          Fuentes para documentar con criterio.

          Esta biblioteca enlaza recursos externos y no reproduce imágenes ni obras de terceros.
